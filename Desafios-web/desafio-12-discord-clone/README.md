# 🚀 Desafio 12 — Clone Discord

Clone educacional da página inicial do Discord, criado com **HTML5, CSS3 e JavaScript puro**. O projeto reproduz a identidade visual moderna da plataforma com conteúdo autoral, ilustrações em SVG e layout totalmente responsivo.

> Este projeto foi desenvolvido exclusivamente para fins de estudo. Discord é uma marca registrada de seus respectivos proprietários.

## 🖼️ Preview

![Preview do Clone Discord](assets/preview.png)

## ✨ Funcionalidades

- Navbar com navegação por âncoras
- Hero section inspirado na página oficial
- Seções informativas com ilustrações próprias
- Botões com estados de hover
- Menu mobile animado
- Rolagem suave
- Fechamento do menu pela tecla `Esc` e clique externo
- Layout responsivo para desktop, tablet e celular
- Estrutura semântica e acessibilidade básica

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- SVG
- Google Fonts

## 🚀 Como executar

1. Faça o download ou clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/discord-clone.git
```

2. Entre na pasta:

```bash
cd discord-clone
```

3. Abra o arquivo `index.html` no navegador.

Também é possível usar a extensão **Live Server** do VS Code.
